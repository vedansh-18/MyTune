# Contributing to MyTune

Thank you for your interest in contributing to **MyTune**! We welcome bug reports, feature suggestions, and code contributions from the open-source community.

---

## 1. How to Report Bugs

If you find a bug or unexpected behavior:
1. Check the [GitHub Issues](https://github.com/vedansh-18/MyTune/issues) to ensure it hasn't already been reported.
2. Use the **Bug Report** template when filing a new issue.
3. Provide step-by-step instructions, device details (Android OS version, model), logcat stack traces (if applicable), and expected vs actual behavior.

---

## 2. Suggesting Enhancements

Enhancement requests are tracked as GitHub issues:
1. Use the **Feature Request** template.
2. Clearly describe the feature, why it would be useful, and any design ideas.

---

## 3. Submitting Pull Requests

1. Fork the repository and create a new feature branch (`git checkout -b feature/my-new-feature`).
2. Follow existing code style conventions and preserve documentation.
3. Ensure the app compiles cleanly:
   ```bash
   ./gradlew assembleDebug
   ```
4. Commit your changes with clear, descriptive commit messages.
5. Push to your branch and open a Pull Request against `main`.

---

## 4. Code of Conduct

Please note that this project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold these standards.
