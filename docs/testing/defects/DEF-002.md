# Defect Report — DEF-002

**Defect ID**: DEF-002  
**Title**: Track title sorting in "All Songs" tab is case-sensitive (sorts uppercase A-Z before lowercase a-z)  
**Date Logged**: 2026-09-19  
**Reported By**: User / QA Tester  
**Environment**: Android Physical Device / Emulator  
**Build / Version**: v1.0.0 (versionCode 1)  
**Module**: Media Scanning / MainActivity  
**Severity**: Minor  
**Priority**: P2 - Medium  

---

## 1. Description & Preconditions

* **Preconditions**: Device storage contains tracks with mixed case titles (e.g. `Alpha.mp3`, `Zeta.mp3`, `apple.mp3`, `banana.mp3`).
* **Summary**: When scanning tracks via MediaStore, track sorting sorts all uppercase titles (`A-Z`) before lowercase titles (`a-z`), resulting in an ordering of `Alpha` -> `Zeta` -> `apple` -> `banana` instead of case-insensitive alphabetical order (`Alpha` -> `apple` -> `banana` -> `Zeta`).

---

## 2. Steps to Reproduce

1. Place mixed-case audio files in media storage (`Alpha`, `Zeta`, `apple`, `banana`).
2. Launch MyTune and view "All Songs" tab.
3. Observe track list ordering.

---

## 3. Expected vs Actual Results

* **Expected Result**: Tracks are sorted in case-insensitive alphabetical order (`Alpha`, `apple`, `banana`, `Zeta`).
* **Actual Result**: Tracks are sorted case-sensitively (`Alpha`, `Zeta`, `apple`, `banana`).

---

## 4. Evidence & Reproducibility

* **Reproducibility**: Always (100%)
* **Evidence**: Source code in `MainActivity.java` line 481:
  ```java
  String sortOrder = MediaStore.Audio.Media.TITLE + " ASC";
  ```

---

## 5. Lifecycle & Resolution Tracking

* **Status**: Closed / Resolved  
* **Root Cause Analysis**: Standard SQL query sort order `TITLE ASC` in MediaStore query performs ASCII byte sorting by default.  
* **Resolution**: Updated `sortOrder` in `MainActivity.java` to `MediaStore.Audio.Media.TITLE + " COLLATE NOCASE ASC"`, and applied `Collections.sort(allSongs, (f1, f2) -> f1.getName().compareToIgnoreCase(f2.getName()))` to guarantee case-insensitive alphabetical sorting across both MediaStore and file system fallback scans.
