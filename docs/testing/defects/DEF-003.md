# Defect Report — DEF-003

**Defect ID**: DEF-003  
**Title**: Audio files with .3gp extension are excluded during MediaStore scanning  
**Date Logged**: 2026-09-19  
**Reported By**: User / QA Tester  
**Environment**: Android Physical Device / Emulator  
**Build / Version**: v1.0.0 (versionCode 1)  
**Module**: Media Scanning / MainActivity  
**Severity**: Minor  
**Priority**: P2 - Medium  

---

## 1. Description & Preconditions

* **Preconditions**: Device storage contains a valid audio file with extension `.3gp` (e.g. `recording_sample.3gp`).
* **Summary**: Although `.3gp` is listed in `SUPPORTED_EXTENSIONS`, `.3gp` files do not appear in the scanned track list during normal MediaStore scanning.

---

## 2. Steps to Reproduce

1. Place an audio `.3gp` file in local storage.
2. Launch MyTune and view "All Songs" tab.
3. Observe track list.

---

## 3. Expected vs Actual Results

* **Expected Result**: `.3gp` audio file is scanned and displayed in the track list.
* **Actual Result**: `.3gp` audio file is absent from the track list.

---

## 4. Evidence & Reproducibility

* **Reproducibility**: Always (100%)
* **Evidence**: Source code in `MainActivity.java` line 480:
  ```java
  String selection = MediaStore.Audio.Media.IS_MUSIC + " != 0";
  ```
  Android's system MediaScanner indexes `.3gp` files under generic audio or video rather than setting `IS_MUSIC != 0`.

---

## 5. Lifecycle & Resolution Tracking

* **Status**: Closed / Requirement Withdrawn  
* **Root Cause Analysis**: `.3gp` files are generic 3GPP container files commonly used for low-quality voice/call recordings rather than standard music files.  
* **Resolution**: Per project requirements update, `.3gp` extension support was completely removed from `SUPPORTED_EXTENSIONS` in the application source code and SRS specification. `.3gp` is no longer a supported music format in MyTune.
